# Tools

Lightweight helper scripts for MIDI management:

- `change_tempo.py` — scale MIDI tempo by multiplier
- `inspect_midi.py` — quick inspector for message counts and metadata
- `pedal_profiles.json` — example pedal presets
- `reclean_everything.py` — bulk update pedal settings for all processed files
- `reclean_with_ai.py` — uses Gemini to suggest cleaning profiles
- `reprocess_all.py` — bulk re-clean library files
- `delete_missing_metadata.py` — cleanup for out-of-sync database entries
